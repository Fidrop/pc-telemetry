# 首次启动温度驱动安装引导

2026-11-13，Windows 1.0-preview10。Android沿用1.0-preview9，配对信息与协议不变。

## 行为

- 普通双击/托盘启动先请求管理员授权。检测64位注册表中的PawnIO版本，并实际尝试打开驱动设备；2.0及以上且可用时直接采集，不重复下载安装。
- 首次缺失或不可用时显示“开启CPU温度采集”。用户点击“安装并继续”才会联网下载官方PawnIO 2.2.0并安装。
- 选择“暂不安装”后继续使用其他指标，在当前Collector数据目录保存暂缓标记，后续启动不反复弹窗。托盘新增“温度采集驱动”入口，可随时补装或检查状态。
- 初次安装在启动采集worker之前完成。托盘补装成功后先停止旧采集、释放运行资源，再以相同参数和同一数据目录启动Collector，保留证书、配对与GPU选择。
- 下载阶段可取消；安装阶段等待官方程序退出，防止中途关闭引导。断网、下载超时、校验错误、安装退出错误均可重试或暂缓。
- 安装返回需要重启Windows，或安装后驱动设备尚不可用时明确提示用户自行保存工作并重启，不自动重启Windows。退出成功但未检测到驱动不计为成功。
- 诊断命令、worker与手机端不弹安装窗口。
