# 配对与安全草案
阶段1已实现回环WSS、证书固定与DPAPI加密开发凭据，secrets子目录限制当前用户访问。完整首次配对、撤销和凭据轮换仍属阶段5。具体实现范围见docs/stage-1-report.md。
采用 WSS（TLS 1.2+，优先 TLS 1.3），不实现明文 ws 降级。默认端口 47631，可改。

## 首次信任
Collector 首次生成设备身份和自签名证书，私钥用 DPAPI CurrentUser 保护，文件 ACL 仅当前用户。mDNS 只公告 ID、版本、端口，发现数据不构成信任。
手机初次握手获得证书，停留在未信任向导，显示 SHA-256 指纹。Windows 配对窗口显示相同指纹，用户必须完整核对并显式确认，确认前不传配对码或凭据。可在后续提供包含指纹的本地二维码作为便利方式。
手动 IP 同样经过指纹核验。Android 专用 TLS 验证器仅对用户确认的那个证书/公钥 pin 放行，不使用全局 trust-all，不自动接受变更。IP 改变无需解除 pin，证书变更须重新配对。

## 一次性配对与长期凭据
用户从托盘打开 120 秒配对窗口，密码学随机生成 8 位十进制码，每个窗口全局最多 5 次失败，按来源限速并限制并发。错误统一响应，使用常量时间比较。
TLS 已验证后发送 pair.request。成功原子消费配对码，生成 256-bit 随机 token 和 credentialId，WSS 内只交付一次。服务端 DPAPI 保存认证资料，手机 Keystore AES-GCM 加密后保存至私有存储，关闭系统备份以防迁移残留。
重复请求不得重复签发，断线导致响应丢失需重新开启配对窗口。认证成功前不发送 telemetry。长期 token 仅在 pinned WSS 中发送，日志不记录码、token 或授权头。
支持主动撤销与重新配对，失败认证不无限重试。仅绑定本地网络地址，防火墙仅允许私有网络配置文件；公共网络默认不开放。
凭据轮换需先确认新凭据持久化再撤销旧凭据，协议细节在阶段 5 编写故障测试后落实。

## 边界与验收
指纹核对是首次防中间人所必需的用户步骤。局域网发现可能被伪造，不能跳过核对。系统账户或设备被攻破不在链路加密保护范围内。
应用消息限制 16 KiB、超时、严格类型与数值校验、每连接速率限制。GPU 选择仅接受枚举 ID，拒绝文件路径、命令和未知操作。
阶段 1 的服务仅在回环接口调试，真实局域网数据链路须有证书固定与受控测试凭据；完整首次配对 UX 属阶段 5。任何临时测试凭据均不作为发布默认值。
待验证包含中间人证书、重放/过期配对码、并发消费、认证限速、凭据损坏、撤销、证书变化与响应丢失。
