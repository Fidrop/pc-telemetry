# SPORT麦克风拾音条与灵敏度
2026-11-12，Android1.0-preview8（versionCode9）。

## 使用与视觉
设置增加“SPORT麦克风拾音条”开关，默认关闭。用户开启时通过Android原生录音权限弹窗授权；拒绝则保持关闭并提示，不创建录音会话。SPORT两侧增加红色渐变32段音量条，匹配夜间亮度和OLED微移。左右镜像显示同一单声道响度，不表示立体声或声源方向；HUD不绘制拾音条。

灵敏度0–100，默认50。靠近音箱可调低，安静时调高，拖动实时预览，松手后保存到DataStore；不在拖动中反复写盘或重启AudioRecord。0是最低灵敏度，并不等于关闭麦克风；停止拾音请关闭开关。

映射为相对数字响度（dBFS），不是校准的环境分贝。默认参考范围约-55到0dBFS；灵敏度50相当于0dB显示增益，最低约-36dB、最高约+18dB，配合快上升/慢回落平滑。设置只调整拾音条响应，不改变手机硬件输入增益，也不能恢复已削波的声音细节；音箱过近时可拉开距离。

## 生命周期与隐私
仅在开关开启、权限已获准、SPORT仪表可见、引擎未关闭、Activity处于RESUMED时创建AudioRecord。关闭、HUD、ENGINE OFF、退后台或控件销毁时取消采样并stop/release。系统撤销权限后恢复前台会关闭保存的开关，需要重新开启授权。

16kHz单声道PCM16，每约50ms读取短窗口，计算RMS后只把归一化数值交给UI。PCM只在当前缓冲区使用，不写文件、不转写、不存入设置、不进入Windows协议或网络。默认关闭路径不创建AudioRecord；静音时不生成随机跳动。无设备、权限或格式错误会停止并提示。

## 检查
- 实际Debug构建、核心测试任务与Lint通过，0错误28警告，见microphone-final-build.txt和microphone-suite.txt。
- scripts/test-microphone.ps1仅接受专用模拟器，会修改本应用测试设置与录音权限。原生弹窗检查拒绝后保持关闭，以及重新允许后录音，不以单纯pm grant替代用户授权流程。
- 通过AudioManager活动录音会话检查：默认关闭无录音；开启存在会话；关闭/切HUD/引擎关闭/后台后会话为空；回前台或SPORT后按保存的开关恢复。灵敏度变化前后session ID一致，保存后读回一致。
- PCM夹具检查静音为零、强信号调低灵敏度后不满格、弱信号调高后响应上升，没有将夹具作为实际拾音显示。
- microphone-regression-tests.txt记录5项既有主题、设置、时钟电量、引擎和80%自检回归通过。
- 模拟器未启用allow-host-audio，输入为虚拟静音，没有使用电脑真实麦克风。docs/qa/microphone截图展示静音轨道和设置，不能当作实体手机声音响应或性能验收。
- 测试结束撤回模拟器本应用录音授权，见microphone-final-permission.txt。资源检查记录见microphone-release-checks.txt。

实际手机拾音、近音箱最佳灵敏度和新增绘制的实机性能仍待确认；既有Windows工作集、游戏影响、长期稳定性未完成项保持原状态。未增加后台录音服务或第三方依赖。
