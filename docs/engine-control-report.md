# SPORT引擎控制与启动扫表
2026-11-10，Android1.0-preview7（versionCode8）。

## 交互
SPORT中央原ONLINE与数据年龄区域改为ENGINE STOP与操作提示。点击进入黑色全屏ENGINE OFF页，白色大字以约1.7秒的明暗周期闪动，下方圆形ENGINE START按钮由多层金属渐变、抛光高光、内凹暗面、红色细边与投影绘制，不使用整张截图铺底。

必须持续按住按钮至少1000ms才启动；短按、提前松开、手势取消会清空按压进度并留在关闭页。按压外圈显示红色进度，按住时约每140ms请求一次系统CLOCK_TICK轻触感，不使用持续长振或循环振动波形。系统触感设置关闭或硬件不支持时可能无震感；本次模拟器不能验证真实马达强度，仍需手机体验确认。

启动时关闭页淡出，仪表页在450ms内淡入并略微放大到正常尺寸。六项仪表进行约650ms扫到80%的启动显示自检，停留约120ms，再用650ms平滑回到实时读数。温度自检读数约80°C，内存条和使用率约80%，屏幕明确标记STARTUP SELF TEST，内存容量位置显示SELF TEST。时钟和手机电量保持真实，不参与扫表；无实际来源的指标在自检结束后恢复N/A。

这只是SPORT显示状态和显示自检，不向电脑发送关机、停采样或伪造遥测。采集连接与60秒历史继续工作，以免影响HUD；HUD不显示这套启动按钮/扫表。关闭页仍可左右滑动切换HUD，回到SPORT保持关闭状态，直至再次长按启动。切换主题、退后台或控件销毁会取消正在进行的按压与触感请求。

SPORT连接状态与DEMO标记移到左上标题下方；数据年龄仍保留在辅助功能描述中。真实读数、离线和DEMO继续区分。界面状态使用rememberSaveable处理活动重建，未增加第三方库或振动权限。
