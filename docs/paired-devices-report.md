# 已配对设备列表与电脑名称

2026-11-13，Android 1.0-preview9（versionCode 10），配套新版 Collector。

## 使用

设置顶部的“连接已配对设备”显示保存过的电脑。主名称由 Windows 设备名提供，本机为用户已确认的 FIDROP-MECH；地址为辅助信息。旧 Collector 未提供名称时暂用主机地址。最多保存 16 台电脑，同一时刻只连接一台。

- 勾选：连接已有设备；正在连接时显示横杠，收到有效数据后显示勾。
- 取消勾选：停止连接与自动重试，保留配对凭据。再次勾选即可恢复，不需要关闭应用或重新输入配对码。
- “连接新设备”：在同一列表内打开原有证书核对与一次性配对流程。旧的独立“连接与配对”“重新配对”“断开”设置入口已移除。
- 选择另一台会停止当前连接。应用重新启动仍连接上次选择的电脑；手动断开在本次应用会话内保持。
- 若凭据失效或证书变化，会提示重新核对与配对，不绕过证书校验。连接新设备也可对同一电脑更新配对。

## 存储与兼容

原单设备 encrypted_profile 在 DataStore 原子更新中迁移到 encrypted_profiles_v2，多设备列表仍用 Android Keystore AES-256-GCM 加密。旧 credentialId、token、证书指纹与 deviceId 不变，不影响其他界面设置。新增配对按 deviceId 替换同一设备，不覆盖其他电脑；名称不作为身份依据。

WSS握手可选 device-name 能力。声明能力的新客户端从成功配对结果或认证hello读取 Windows 设备名；已有配对可由hello自动补充名称。旧客户端收到原字段集合，新客户端亦兼容未提供名称的旧Collector。

## 验证

- Windows 73项检查通过，包含旧客户端无新增字段与新客户端认证后收到真实Windows设备名。
- Android核心19项通过，3项需独立凭据的JVM联调按原设计跳过；另外已通过真实Windows/API29模拟器联调。
- Android Keystore设备测试2项通过：精确复现v1加密格式并迁移；多设备保存/切换/同设备更新/名称更新/删除单设备，不影响另一台的凭据。
- 真实Windows配对、无名称旧档案由认证hello补名称、保存加密信息、实际点击勾选框断开再重连、同凭据恢复遥测、连接新设备入口、远端撤销后旧token失效通过。
- 截图：qa/devices/paired-devices.png 与 sport-live.png，真实数据；回环地址为专用模拟器转发。
- 5项原功能回归：SPORT/HUD切换、设置与语言持久化、时间/电量、按住启动引擎、启动自检不覆盖真实遥测。
- Android Lint 0错误、28警告；未新增已知警告。实体手机、跨设备mDNS、多台真实电脑切换与长时间运行仍待实测。
