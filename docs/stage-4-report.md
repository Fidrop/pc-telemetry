# 阶段4记录
HUD已原生绘制深蓝黑青橙航电布局，左侧直线负载、中央0–100%与-60s至Now坐标、右侧唯一温度和内存、底部连接状态与数据年龄。
曲线只读取真实或明确DEMO的固定60点缓冲。断线停止新增，过期点移出窗口，缺失和长间隔断开连线。首次样本较少时不填造60秒曲线。
星空和地球弧线使用轻量Canvas，无实时3D。主题可横向滑动切换。
Android10模拟器DEMO与切换检查通过，见docs/qa/hud-demo.png。已改为数据驱动插值滚动，解决自定义无限帧循环影响自动检查空闲的问题。
地球材质与切角边框等精细视觉还原可继续优化，未宣称逐像素复刻。小米8 Android14 HyperOS2待实机。
