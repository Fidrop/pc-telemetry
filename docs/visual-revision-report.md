# ROG / HUD / 设置面板视觉迭代
2026-11-10，Android 1.0-preview2（versionCode 3）。本次覆盖用户的三项修改：补齐ROG标志、增强科幻航电HUD、提高设置可读性；随后按截图将GPU面板内容向下对齐CPU。

## 修改
- SPORT顶部及中央补齐独立ROG眼睛矢量；HUD顶部使用小尺寸ROG。设置→标志样式可切换到不含第三方商标的原创TELEMETRY徽标，并保存到DataStore。素材来源与品牌声明见brand-assets.md。
- HUD改用双层切角发光边框、芯片图标、独立CPU/GPU面板、斜切负载段、细密网格、轨道刻度、航天器剪影，以及带陆地/城市灯光/经纬网的地球地平线。所有装饰均程序绘制，不以整张样稿铺底；六指标、曲线与离线语义保持原生。
- CPU青/GPU橙，历史曲线保留真实缓冲与断点。低透明光晕采用少量描边，无虚构延迟、坐标或运行时间。
- GPU图标、标题、百分比、stale标签、负载条和GRAPHICS说明整体下移30个1774×887设计坐标像素，使相对面板顶部的留白与CPU相同；边框和数据来源不变。
- 设置深色Surface显式指定浅色正文，选项/开关分别指定选中与未选中颜色，修复自定义深背景继承黑字。中英文均截图检查；较低位置的设置可滚动访问。
- HUD长状态文字限制宽度，DEMO显示简短标记，避免与REFRESH重叠；SPORT两处不同尺寸徽标使用独立VectorPainter缓存，防止顶部标志被裁切。

## 渲染检查与限制
API29 / 2248×1080模拟器、Debug、每主题稳定3秒后捕获15秒gfxinfo；最终使用静态场景独立离屏合成层，减少复杂装饰重绘。最终SPORT421帧，p50/p95/p99为29/48/61ms；HUD656帧，34/53/65ms。卡顿比例分别84.56%/98.17%，不能宣称60fps达标。
一次未开启离屏合成的中间检查HUD p95达到150ms，提示需要缓存场景；最终检查降至53ms，但主机负载和虚拟GPU影响很大，这不是严格A/B实验，仍需目标手机复测。原始数据位于docs/qa/visual-revision/performance，采集测试通过仅表示获得有效帧，不表示流畅度验收通过。

物理手机、Windows工作集≤80MB、游戏影响和长期稳定性仍沿用已知未验收状态。已更新源码、安装包及交付脚本；二进制与源码ZIP逐文件核验SHA256。
