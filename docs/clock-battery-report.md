# 时间、电量与SPORT标志调整
2026-11-10，Android1.0-preview3（versionCode4）。

## 实现
SPORT保留中央ROG（或原创TELEMETRY替代徽标），去除顶部重复眼睛，标题左侧改用红色细竖线。连接状态和数据年龄下方增加银色边框/烟色玻璃/红色下沿的小表框，显示HH:mm:ss；框下是手机电量小窗，并避开RAM/VRAM标题。
HUD在CPU/GPU USAGE图表上方增加青色切角时钟；采用Canvas原生七段数码管，包括小时、分钟、秒。手机电量位于右上区域的HUD MODE标记下方。

时间采用手机本地时区、24小时制、ASCII数字和补零，每秒校准显示，跟随系统时间/时区。电量来自Android系统ACTION_BATTERY_CHANGED粘性广播，显示真实百分比、充电闪电；未充电且≤15%时标红，不可用显示N/A。PHONE明确表示手机电量，DEMO模式也不会将演示电量冒充系统值。

前台STARTED生命周期内更新时间和监听电量，进入后台注销监听、暂停计时，恢复前台重新读取。手机信息与遥测数值使用不同来源；未修改Windows六指标协议、60秒历史和离线单调时钟。时钟/电量采用独立离屏合成层，避免每次指针或曲线动画都重新记录数码管绘制。

## 数码时钟字距调整（2026-11-10，1.0-preview5）
两个主题共用的数码管数字间距由字高的0.14增加到0.26，时、分、秒继续通过冒号分组，整体保持居中。数字高度和表框尺寸不变，增加字距后仍在两个主题表框内，重点改善“16”等相邻竖段的分辨。
实际构建与Lint结果见clock-spacing-build.txt；两主题切换及真实时间跳动检查见clock-spacing-ui-tests.txt。截图在docs/qa/clock-spacing，已用于核对数字间隙、冒号与左右边框。此调整不修改时间来源、24小时制、电量灯条或遥测逻辑。

## 数字1的占位修正（2026-11-10，1.0-preview6）
用户截图16:11:56中分钟与前一冒号之间的空白，来自七段数码管数字1只点亮右侧竖段，却占用完整数字格。上一版统一加大字距后，这段空白被放大。
本版将1的排版宽度缩至实际竖段笔画宽，并平移右侧竖段到该位置；不再为1绘制占满数字格的暗色8字底纹。保留上一版数字间距、冒号和整体居中；其他数字保留常规宽度并计入描边边界，避免挤压。两个主题同步修正，时间来源与格式不变。
构建/Lint记录为clock-kerning-build.txt，主题及实际时间跳动检查为clock-kerning-ui-tests.txt；实际截图位于docs/qa/clock-kerning。
