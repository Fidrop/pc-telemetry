## 共同实现
以 2248×1080 横屏为设计坐标，依据安全区域、刘海和系统手势边距等比调整。其他横屏比例通过约束布局重排，保证字体可读，不能强行裁切。
Compose Canvas 绘制动态刻度、数字、指针、灯条和曲线，字体采用系统中文与等宽数字，正式字号/位置/颜色以补图审阅为准。
设置按钮右上角、长按打开半透明浮层，左右滑动切换主题。中英文本使用资源文件，前台常亮、沉浸式、系统亮度，夜间降低亮度与装饰对比。
像素微移拟每分钟移动 1–2 个物理像素并限制总幅度，布局预留安全边距，允许关闭。启动自检 1–2 秒明确标记自检，结束后才呈现真实读数。
N/A 与 stale 分开，离线保留最后读数并显示年龄。DEMO 以持续可见标识隔离，进入/退出清空趋势，断线不自动进入演示。

## SPORT
黑底、银白刻度、红指针与高负载区，细碳纤维与金属边框。
左 CPU、右 GPU 双主表，温度各置于表内唯一位置。底部 RAM/VRAM 百分比和容量，顶部标题、主题、分段负载灯与可替换品牌素材。
样稿 0 位于左下、50 位于正上、100 位于右下。Canvas 坐标（右为0°、顺时针为正）采用 angle=135+2.7×percent，绘制指针用 cos/sin 计算端点。0/50/100 分别为135/270/405°。数字与指针使用相同动画值。高负载红区约从80开始，顶部9段灯的精确阈值在阶段3审阅。
无 60 秒趋势，背景素材仅局部纹理。默认提供 PC TELEMETRY 自有文字替代 ROG，第三方标识独立资源，无官方授权暗示。

## HUD
深蓝黑底、青色细线、少量橙色、等宽数字。左 CPU/GPU 直线刻度和分段负载，中央 CPU 青/GPU 橙双曲线，0–100% 纵轴和 -60s 到 Now 横轴。
右侧唯一的 CPU/GPU 温度及 RAM/VRAM 百分比容量，底部 ONLINE/OFFLINE、数据年龄和必要连接信息。
图表表达时间变化，不额外叠加重复即时数字。断线停止新增点，随时间过期的区域留空。星空、地球弧线和轨道采用低对比静态局部素材，扫描效果可关闭。
避免机械圆表与重复圆角卡片，不展示虚构坐标、延迟和运行时间。
