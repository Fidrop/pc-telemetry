# PC Telemetry 预览版使用说明

## 安装
Windows 10/11 x64：完整解压Windows便携包，双击Collector.exe，程序进入系统托盘。整个目录需要保留；无需另装.NET。当前版本未签名，系统可能提示未知发布者，请先核对随附SHA256。

Android 10及以上：将PC-Telemetry-1.0-preview9-debug.apk传到手机，允许文件管理器安装后打开。Preview 10更新Windows端，手机端沿用Preview 9。这是用于验证的Debug安装包，不是商店正式版。更换开发电脑可能更换Debug签名，覆盖安装失败时需卸载旧版并重新配对。

### 首次开启 CPU 温度
正常启动PC端会请求管理员授权。没有可用PawnIO驱动时，首次启动弹出“开启CPU温度采集”：点击“安装并继续”，程序联网下载官方PawnIO 2.2.0，验证完整性与数字签名后安装；成功后自动开始采集。下载阶段可取消；安装阶段请等待完成。

选择“暂不安装”仍可使用占用率和内存，温度可能显示N/A，后续启动不反复弹窗。需要补装时，在电脑托盘菜单选择“温度采集驱动”；安装完成后Collector会自动重启，保留原配对。已有可用驱动的电脑跳过安装。若安装程序要求重启Windows，界面会明确提示，由用户保存工作后自行重启。

首次安装需访问GitHub的官方安装包；断网、校验或安装失败会保留重试入口。官方安装包版本固定，校验不通过时不会运行。安装并不保证所有硬件都提供全部温度传感器。驱动可在Windows“已安装的应用”中作为PawnIO单独卸载。

## 首次连接
1. 手机与电脑连接同一可信家庭/办公网络。Windows网络类型须为“专用”或域网络，公共网络不会开放服务。只在你信任该网络时自行更改；程序不会自动更改网络类型。
2. 双击电脑托盘图标，打开“首次配对”窗口，窗口列出连接地址、完整证书SHA256指纹与8位配对码。
3. 手机选择发现的电脑，或手动填写电脑窗口显示的完整地址，例如 `wss://192.168.1.10:47631/v1/stream`。不要填写手机自己的127.0.0.1。
4. 点击检查指纹，逐字核对与电脑相同后确认，再输入配对码。代码120秒有效、仅能使用一次，最多允许5次失败。过期后关闭并重新打开电脑配对窗口。
5. 连接成功后显示ONLINE和真实读数。DEMO为明确标识的演示数据，不能用于判断电脑状态。

系统防火墙首次提示时仅允许专用网络。若未出现提示且无法连接，可在Windows防火墙高级设置中，为实际Collector.exe添加入站TCP47631规则，仅专用/域配置文件、远端本地子网；mDNS发现需要UDP5353。不要关闭整个防火墙或开放公共网络。修改端口后需同步调整规则和手机地址。

## 日常使用
左右滑动切换SPORT/HUD，点击齿轮或长按打开设置；可修改语言、主题、标志样式（ROG/原创TELEMETRY）、夜间模式、像素微移、GPU与连接设置。应用前台常亮，进入后台停止连接。重新配对会尝试撤销电脑端旧凭据并清除本地信息；电脑离线时撤销可能失败，可在电脑托盘“移除全部配对”中撤销。

托盘菜单可启用当前用户登录自启；移动便携目录后应重新设置自启。退出请使用托盘菜单“退出”。网络地址或网络类型改变后重启Collector，再检查连接地址。

## 读数与隐私
采样约每秒一次，仅展示CPU/GPU使用率、RAM、专用VRAM和CPU/GPU温度。硬件不提供的指标显示N/A；集成显卡共享内存不会冒充专用VRAM。stale/陈旧表示保留的旧读数。5秒没有有效数据进入离线，保留最后值并增加数据年龄。

数据通过局域网加密连接发送，不需要云服务。Windows配对信息在当前用户LocalAppData/PcTelemetry/collector中，以DPAPI保护；Android使用Keystore保护本地凭据并排除备份迁移。不要共享运行数据目录。重新安装系统或更换账户/设备后重新配对。

## 故障排查
- 找不到电脑：先用窗口内完整地址手动连接，检查同一Wi-Fi、VPN、AP客户端隔离与防火墙。mDNS被网络屏蔽时手动地址仍可使用。
- 托盘提示仅本机：确认可信网络设为专用，检查是否选到虚拟网卡，重启Collector。公共网络不提供LAN服务。
- 指纹不同：取消配对，确认连接到正确电脑。更换电脑端身份文件会改变指纹，需要重新核对。
- N/A：此硬件/驱动当前没有提供该传感器，程序不会为填满数值而生成假数据。正常双击Collector或以托盘方式启动时会自动弹出Windows管理员授权；取消授权则退出，不重复弹窗。命令行诊断与测试模式保持当前权限。
- 安全更新：Windows采集库已升级到LibreHardwareMonitorLib 0.9.6，移除旧版WinRing0依赖，不再释放Collector.sys。Preview 10提供用户确认后的PawnIO安装引导；未安装时部分温度/电压可能显示N/A，管理员权限本身不能替代驱动。
- 若旧预览包触发Defender的VulnerableDriver:WinNT/Winring0告警，请保留隔离结果并更换新版完整目录；不要恢复旧Collector.sys，也无需关闭防护或添加排除项。
- 端口占用或启动失败：退出旧实例，检查47631端口。不要同时运行两份使用相同数据目录的Collector。
- 安装包无法覆盖：可能Debug签名变化，卸载后重装会丢失本地设置和配对，需重新配对。

性能目标、设备适配与未验收项见同包“已知问题.md”。

## 时间与手机电量
两主题显示手机本地24小时制时间（HH:mm:ss），不是电脑时间。PHONE电量来自手机系统；闪电表示充电，无法读取显示N/A。SPORT顶部10格灯条显示电量（每格10%，余量按比例填充）：>60%绿色，20%–60%黄色，<20%红色，图标与数字位于灯条上方；HUD未充电且≤15%时标红。时钟和电量独立于电脑连接，离线时仍可显示，后台暂停更新。SPORT小表框位于状态和数据年龄下方，HUD位于趋势图上方。SPORT仅保留中央品牌标志。

## SPORT引擎按钮
点击中央ENGINE STOP进入关闭页。持续按住圆形ENGINE START至少1秒，外圈进度完成后显示启动过渡和约80%扫表，再恢复实时数据；提前松开会取消。白色ENGINE OFF文字缓慢明暗闪动。按住期间为轻微间歇触感，是否能感到由手机硬件和系统触感设置决定。启动扫表明确标为SELF TEST，不是真实传感器读数。HUD不参与此逻辑，关闭页可滑动切换HUD；该操作不会关闭电脑或停止电脑采样。

## 麦克风拾音条
设置中开启“SPORT麦克风拾音条”，允许录音权限后，两侧红色条显示手机拾音强度。默认关闭，关闭会隐藏并释放麦克风；切HUD、ENGINE OFF和退后台也会释放。音频只用于即时音量计算，不保存或发送。
灵敏度默认50，靠近音箱时调低、安静时调高；拖动实时预览，松手保存。灵敏度0是最低响应，停止拾音应关闭开关。两个条是同一单声道信号的镜像，并非立体声分离，此显示不是校准分贝计。若无反应，检查Android录音权限、系统麦克风隐私开关和其他录音应用占用。

### 已配对设备与重新连接
在设置顶部“连接已配对设备”列表中，勾选电脑以连接，取消勾选以断开。横杠表示正在连接或重试，勾表示已收到有效数据。凭据仍保留，再次勾选即可恢复。列表内“连接新设备”可新增电脑或更新失效的配对；Windows名称只用于显示。更改IP后仍需使用正确地址，名称显示不等于已实现IP自动更新。
