# 原始需求补充
原始15节需求与baseline.sha256保持不变；后续用户明确修改记录于此。

## 2026-11-10：时间、电量和SPORT品牌位置
- SPORT避免重复ROG，保留中央标志，顶部改为简洁项目标题。
- 两主题增加当前时间，24小时制HH:mm:ss。SPORT置于连接状态和数据年龄下方，独立里程表式边框；HUD置于CPU/GPU USAGE图表上方，数码管风格。
- 两主题增加当前电量，由实现选择适配主题的位置。实现采用手机系统电量并明确PHONE标记，时间采用手机本地时间。
- 本补充不向Windows六指标协议加入时钟或电池字段；离线判定仍使用单调时钟，不能被系统时间校准影响。

## 2026-11-10：SPORT电量灯条
SPORT顶部灯条改为10格手机电量，每格10%；>60%绿色，20%–60%黄色，<20%红色；数字电量与电池图标位于灯条上方，移除时钟下方的重复电量。

## 2026-11-10：SPORT引擎控制
用户要求SPORT状态区改为引擎控制入口，点击进入全屏闪动ENGINE OFF与金属圆形ENGINE START按钮，持续按住1秒才启动，提前松开不启动，期间为轻微连续脉冲触感；HUD不受影响。追加启动页面过渡和六指标先扫到约80%再恢复实时显示。实现将扫表标记为启动自检，不改变原始遥测或历史。

## 2026-11-12：SPORT拾音条与灵敏度
用户要求调用手机麦克风，SPORT左右增加红色渐变拾音条；设置开关关闭时隐藏并停止麦克风。随后追加灵敏度，防止靠近音箱时始终满格。实现默认关闭、原生授权，0–100灵敏度实时预览并保存；HUD、ENGINE OFF和后台释放录音资源。
