# SPORT顶部电量灯条
2026-11-10，Android1.0-preview4（versionCode5）。

按用户要求，将SPORT原CPU/GPU负载提示灯替换为手机电量条：10格，每格10%。已亮部分按整体电量统一着色：>60%绿色、20%–60%（含边界）黄色、<20%红色。非整十的剩余电量在下一格按比例填充，例如65%为6格全亮加半格；0%不点亮，未知电量全部灰色并显示N/A。

手机电池图标、PHONE标记和数字百分比居中放在灯条上方；保留充电闪电。移除SPORT时钟下方的电量小窗，中央仅保留状态、数据年龄和里程表式时钟。HUD电量样式、24小时制时钟与六项电脑遥测保持原有行为。

实际Debug构建和Lint通过（0错误28警告），既有核心测试任务通过。模拟器两主题切换、真实系统电量读取与时钟跳动2项检查通过，见sport-battery-bar-ui-tests.txt。已检查实际截图docs/qa/sport-battery-bar/sport-demo.png，模拟器真实电量为100%，顶部10格显示绿色，图标和数字在其上方；没有用模拟值替换系统电量。红/黄阈值及部分填充按上述代码规则实现，本轮未改变模拟器电量来伪造真实设备截图。

本次仅修改SPORT电量表达与发布版本，不代表实体手机或此前性能目标已经验收。安装包签名、版本和压缩包SHA256在交付时核验。
