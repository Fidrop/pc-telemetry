## SPORT核对
左右大型双圆仪表，银色金属双边框、白色机械刻度、红针，80–100附近红区。顶部9段灰/黄/红灯，标题和主题位于上栏。两表之间有醒目ROG眼睛及SYSTEM装饰，底部并排RAM/VRAM斜分段条与容量。背景黑色碳纤维和红色边线。
示例CPU42%、58°C，GPU78%、67°C均属于样稿文字，不能用于真实采集或测试结果。CPU/GPU温度各在表内出现一次。
原图中央ROG视觉权重较高，已确认需求要求克制并可替换，实际实现缩减其权重并提供PC TELEMETRY替代。SYSTEM无状态含义，可省去。右上角主题附近需预留设置触控区。
仪表从左下0经顶部50到右下100，Canvas角度映射已修正到visual-design.md。图中指针与百分比存在近似误差，程序以严格数值映射验收。

## HUD核对
深蓝黑底，青色细线切角边框，GPU曲线与负载强调为橙色。左侧CPU/GPU竖向组合区，中央双曲线，右侧温度与内存两区，底部横向状态。轻量地球弧线位于底部，顶部有轨道弧线和航天器装饰。
需要按已确认需求调整的项目
- 左侧重复温度删除，CPU/GPU温度仅保留右侧。
- 底栏LATENCY与UPTIME并非v1监控范围，正式UI不展示样稿中的7ms或00:42:36。
- 装饰罗盘方向数值、无数据来源柱状图与拼写异常副标题不作为实际遥测信息，简化为轻量背景或去除。
- 曲线示例末值与左侧即时值并不完全一致，程序历史点必须来自真实采样，并明确动画过渡。
- CPU青/GPU橙、0–100%和-60s到Now轴保留，断线处留空。图中曲线与填充光晕需减轻重绘负担。
